= memoria

A self-hosted memory layer for AI agents and LLM applications: extracts,
stores, retrieves, and ranks durable facts from conversations, so an
application can recall relevant context about a user, agent, or session
across time instead of replaying full transcripts.

== Crates

Four crates, one shared engine:

[cols="1,3"]
|===
| Crate | What it is

| `core` (published as `memoria-core`)
| The engine: `add`/`search`/`update`/`delete`/`reset`/`history`, three
  pluggable provider traits (LLM, embedding, vector store), no I/O
  framework of its own

| `cli`
| A local-first command-line tool, JSON-snapshot or SQLite persistence,
  one process per invocation

| `server`
| A self-hosted HTTP API over the same engine — auth, rate limiting,
  real hybrid search and reranking, distributed as a non-root Docker
  image

| `mcp`
| A https://modelcontextprotocol.io/[Model Context Protocol] server over
  the same engine, for AI clients (Claude Desktop, Claude Code, etc.) to
  use directly — stdio transport, nine tools
|===

`cli`, `server`, and `mcp` each embed `core` directly and choose their own
persistence; none of them proxy to one another (though `server` and `mcp`
can point at the same SQLite file, since they speak the same on-disk
format).

== Quick start

Requires the pinned toolchain in `rust-toolchain.toml` (installed
automatically by `rustup` on first build).

[source,sh]
----
cargo build --workspace
----

*CLI* (binary at `target/debug/cli`; calls itself `memoria`) — store a
fact under a scope, then query it back. `add` runs fact extraction, so
the stored memory is the extracted fact, not the raw sentence:

[source,sh]
----
$ ./target/debug/cli add "I'm on the Redis migration; Postgres is gone." \
    --user-id alice --agent-id ops --run-id 2026-02-08
9f2c1a...

$ ./target/debug/cli search "what datastore does alice use now" \
    --user-id alice --top-k 5 --explain
9f2c1a...	0.83	Alice uses Redis; Postgres has been removed.
----

`--explain` prints the semantic/keyword/entity-boost breakdown behind each
score. Narrow results with a JSON filter expression (`--filter`), keep a
message verbatim with `--no-infer`, and scope to any combination of
`--user-id`, `--agent-id`, `--run-id`. `--json` switches every command to
machine-readable output.

*Server*:

[source,sh]
----
MEMORIA_API_KEY=dev-key MEMORIA_JWT_SECRET=dev-secret ./target/debug/server
curl -H "Authorization: Bearer dev-key" http://localhost:8080/health
----

The server applies three engine-level ceilings on top of its HTTP body limit,
each overridable and each validated at startup: `MEMORIA_MAX_TOP_K` (default
1000), `MEMORIA_MAX_CONTENT_BYTES` (default 1 MiB), and
`MEMORIA_MAX_METADATA_BYTES` (default 8192). A request over any of them is
rejected with a 400 naming the limit.

*MCP server* — point an MCP client (e.g. Claude Code's `claude mcp add`)
at the compiled `target/debug/mcp` binary; it speaks stdio, no daemon or
network port involved.

== Vector stores

The default store is in-process and needs nothing external. Six backends
exist behind Cargo features: in-memory, SQLite, pgvector, Qdrant, Chroma,
and Milvus. Only SQLite (FTS5) and pgvector (`ts_rank_cd`) implement the
keyword half of hybrid search; on the other four, `search` is semantic
only.

The pgvector backend (`MEMORIA_POSTGRES_URL`, `MEMORIA_POSTGRES_DIMENSION`,
`MEMORIA_POSTGRES_TABLE`) creates its own schema and indexes on first open
— an HNSW index for `<->` search, GIN indexes for keyword and scope
filtering — draws connections from a pool rather than sharing one, and
negotiates TLS when the connection string asks for it (`sslmode=require`
and friends), so managed Postgres works without extra configuration. A
self-signed server certificate needs its CA in the host trust store; there
is no in-repo knob for a custom CA file.

== Ollama

The `ollama` feature points the LLM and embedding providers at a real Ollama
instance. Either `MEMORIA_LLM_BASE_URL`/`MEMORIA_EMBEDDING_BASE_URL` or
Ollama's own `OLLAMA_HOST` supplies the endpoint — the `MEMORIA_*` variables
win where both are set, and an empty value counts as unset. A bare host is
completed, so `OLLAMA_HOST=192.0.2.1` means `http://192.0.2.1:11434`:

[source,sh]
----
OLLAMA_HOST=192.0.2.1 MEMORIA_LLM_PROVIDER=ollama \
  MEMORIA_LLM_MODEL=qwen2.5-coder:1.5b ./target/debug/cli add "..." --user-id alice
----

Requests carry an explicit timeout (2 minutes for generation, 1 for
embedding), `LlmConfig`'s `temperature` is sent in the request's `options`,
and embedding uses the batch `/api/embed` endpoint, falling back to the
legacy per-prompt `/api/embeddings` on a 404 from an older server.

Real providers (Ollama, FastEmbed) and SQLite persistence are behind
Cargo features (`ollama`, `fastembed`, `sqlite` — `mcp` enables `sqlite`
by default). Every default is a real, local, non-AI placeholder so the
whole workspace builds and runs with zero external services.
